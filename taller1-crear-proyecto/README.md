# Taller 1 - Crear un proyecto en Go

**Estudiante:** Jerry Alberto Serna Cevallos
**Asignatura:** Programación Orientada a Objetos
**Unidad:** 1

## Objetivo
Crear y ejecutar un proyecto básico en el lenguaje Go utilizando Visual Studio Code.

## Descripción
El programa muestra en pantalla el nombre del estudiante, su carrera universitaria y su lenguaje de programación favorito.

## Archivos
- `estudiante.go`: código fuente del programa.
- `go.mod`: configuración del módulo de Go.

## Ejecución
1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir la terminal.
3. Ejecutar el comando `go run estudiante.go`.
